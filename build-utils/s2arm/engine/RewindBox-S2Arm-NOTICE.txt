RewindBox: notice for the S2Arm engine (Switch 2 private test IPA)

This application embeds the S2Arm engine (S2ArmEngine.framework and NS2Pro.framework), built in continuous
integration from S2Arm, https://github.com/jhaizhou-ops/S2Arm, at the commit named in license-sources.json beside
this file. S2Arm is Copyright 2026 S2Arm contributors and is licensed under the Apache License, Version 2.0: the
licence is S2Arm/LICENSE, and the contents of S2Arm's NOTICE file are in S2Arm/NOTICE.

RewindBox changed S2Arm to host its engine in this application: the patch series build-utils/s2arm/engine/patches of
the RewindBox repository (https://github.com/TarbleFR/RewindBox), applied to that commit, each change marked
"RewindBox" in comments. The name and SHA-256 of every patch are recorded in S2Arm-native-identity.json at the root of
the application. The preparation library linked into the application (S2ArmPrepare.xcframework: S2Arm's rewriter,
with Capstone and LZ4) and RewindBox's C ports of S2Arm tools are built from the same commit. RewindBox changed S2Arm's
rewriter for that library with the patch series build-utils/s2arm/prepare/patches of the same repository, applied to
that commit, each change marked "RewindBox" in comments (a progress report; the rewritten code is the same). The name
and SHA-256 of every patch of that series are recorded in S2Arm-native-identity.json under "preparePatches".

RewindBox patch 0170 preserves a game's native presentation interval when a generic prepared FPS capability has no
explicit speed-corrected source. Patch 0171 adds a generic, user-started 180-second observation protocol, actual Metal
presentation timing, bounded audio/GC counters, TASK_VM_INFO ledger reporting and a complete recursive VM metadata
census after the timed window. It does not add game assets or circuit-specific policies, change the shader translator,
or claim a measured device speed or energy gain. S2A_RB_BENCH=0 disables the new observation path;
S2A_RB_VM_LEDGERS=0 and S2A_RB_VM_FULL_AUDIT=0 independently disable the additional ledger report and post-window census.
S2A_RB_NATIVE_CADENCE=0 restores the generic FPS-capability behavior preceding patch 0170. These changes are provided
under S2Arm's Apache License, Version 2.0; all upstream and third-party notices remain applicable.

RewindBox patch 0172 records malloc-zone statistics once per minute, with collection timing.
Patch 0173 accounts for selected host allocations owned by translation tables, page/window records,
texture views, pipeline tables, command recordings and audio output buffers. These counters exclude
unobserved driver allocations and are not added to overlapping VM ledgers. Patch 0174 bounds the
reconstructible open pipeline-archive cache by recency, retaining active users and persistent files;
evicted objects are released outside its shared lock. Patch 0175 releases module-owned trap and
far-jump metadata at drained loader retirement. Patch 0176 responds to system memory-pressure
events by releasing cold archive handles and requesting allocator pressure relief outside engine locks.
S2A_RB_HEAP_TRIM=0 restores the IPA 803 paths for these five patches; S2A_RB_HEAP_LEDGER=0 disables
their additional accounting alone. These changes are written for RewindBox under Apache-2.0,
with the existing MIT notices retained for the direct graphics and Ryujinx-derived portions.
They do not change the shader translator, delete player caches, or establish a measured device gain.

RewindBox patches 0177 through 0180 count live guest Metal pipelines, record recent encoder binds and
release idle archive-backed render and compute entries after the GPU submission fence. Private benchmark
reports include shallow allocation sizes, reconstruction times and cumulative long display intervals.
S2A_RB_PSO_CAP=0 restores the IPA 803 pipeline and host-heap policies for this series.

RewindBox patches 0181 through 0185 budget optional Metal texture storage using available iOS process memory,
retire cold scratch textures and upload spares, and track the first use of purgeable speculative copies.
The benchmark distinguishes texture allocations, heap capacity and uploads after eviction.
S2A_RB_TEX_BUDGET=0 selects the IPA 803 policies for these changes.

RewindBox patches 0186 through 0191 coordinate optional prefetch, staging, texture and pipeline retention
using iOS process headroom and memory-pressure events. The private benchmark can observe a continuous
ten-minute session. S2A_RB_MEM_GOV=0 restores the IPA 803 policies.

RewindBox patches 0192 through 0197 measure actual demand for file-backed texture read-ahead, reduce
speculation with poor yield and correlate demand-page misses with long display intervals.
S2A_RB_PREFETCH_ADAPT=0 selects the IPA 803 paths. S2A_RB_POOL_AHEAD=0 keeps neighbour lookahead off.

RewindBox patches 0198 through 0204 measure long presenting-thread intervals and adapt Apple audio
output on underrun. The original comparison paths are available with S2A_RB_AUDIO_GUARD=0 or
S2A_RB_LONGFRAME=0.

RewindBox patch 0205 isolates course-priority scheduling for a two-course comparison on the IPA 803 policies.

RewindBox patches 0206-0209 handle explicit terminal NVN discards, scope Metal 4 producer coverage, measure MetalFX GPU intervals and preserve native D32 copy compatibility.

RewindBox patches 0210 through 0214 preserve terminal discards in the bindless-aware mode, require full clear coverage, instrument MetalFX on its command buffer, support single-plane D32 scaling copies to non-renderable destinations and classify draw-pass entry barriers.

The engine also contains third-party code; S2Arm's own table of it is S2Arm/THIRD_PARTY_LICENSES.md. The exact
licence and notice texts of the components that reach this application are in the folders beside this file. Each is
listed in license-sources.json with its origin (a file of that S2Arm commit, a source archive the engine build fetched
and checked by SHA-256, or a .NET package of its ahead-of-time compilation) and its SHA-256.

No Nintendo data ships with the S2Arm engine in this application: no system file, firmware, key, font or game content of a console. Its system data (S2ArmSystemData) is only fonts under the SIL Open Font License, the IANA time zone database and empty system data synthesised by S2Arm's generator.

The fonts are Noto Sans and Noto Sans CJK, converted by S2Arm's generator into the shared-font format and file names
the engine reads; the time zone data is compiled from an IANA release; the other system data are empty, well-formed
structures written by S2Arm. Their licence texts and provenance are inside S2ArmSystemData (licenses/, SOURCES.tsv).
No game, key or other protected content is in this application: games are exported by the player from their own
console.

RewindBox patches 0215 through 0219 narrow attachment stores before full clears, isolate guest fence wakeups, add opt-in thermal MetalFX Spatial, park invisible HUD refreshes and measure the first observed Fair or higher thermal state.

RewindBox patches 0220 through 0225 add optional title-scoped asynchronous pipeline lookahead and background prewarming, a versioned binary archive, resident render-key normalization, wider shader library reuse and per-frame compilation diagnostics.

RewindBox adds optional tracking of descriptor aliases and sealed NVN command lists, tile clear batching and MetalFX producer reuse. The accompanying checks cover command ordering, attachment values and timing boundaries.

RewindBox adds opt-in resolution retention, verified shadow-caster scaling, prepared MetalFX input sizes and GPU/thermal resolution control. These modifications and their tests are part of the direct Metal renderer.

RewindBox adds build-specific presentation profiles, bounded file advice and texture upload preparation, and display-link pacing with on-screen measurements.

RewindBox limits the hosted NVN2 presentation budget, debounces host cadence changes and adapts retained memory to process compression and thermal state.

RewindBox adds bounded first-use geometry deferral, urgent shader compilation workers, source-wait diagnostics and verified loading of prepared stage libraries for hosted NVN2 games.

RewindBox patches 0472 and 0473 count newly mapped guest pages from the alias bitmap
and skip empty shadow-directory blocks when gathering previous page protections.
These runtime changes are provided under Apache-2.0.

RewindBox patches 0474 and 0475 record uniform guest page groups together and
use a bitmap to find the first free guest handle in its existing partition.
These runtime changes are provided under Apache-2.0.

RewindBox patch 0476 reuses the native per-kind handle count to check the
transfer-memory limit. This runtime change is provided under Apache-2.0.

RewindBox patch 0479 searches the service session table in its existing
circular order without a per-slot remainder. This change is provided under Apache-2.0.

RewindBox patch 0480 rechecks the transfer-memory handle quota atomically with
handle allocation and returns the borrowed range when a concurrent creator used
the final slot. This runtime change is provided under Apache-2.0.

RewindBox patches 0481 through 0483 modify tiled texture upload staging,
task and mesh shader translation, and empty depth/stencil clear handling.
These changes are provided under Apache-2.0.

RewindBox patch 0484 records the full guest resource-memory high-water mark at
the end of physical mapping, while holding the memory lock. This runtime change
is provided under Apache-2.0.
