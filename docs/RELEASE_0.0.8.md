# NeoStation iOS 0.0.8 🎮

This update expands cheat support, brings more immersive touch controls and fixes several stability issues.

- **Expanded unified cheat catalogue:** more sources for RetroArch cores, arcade games, PS2, PS3, GameCube and Wii, available through a single catalogue download.
- **Simpler cheat management:** compatible cheats appear automatically for the detected game, with individual on/off switches and support for importing your own files. Matching takes available region and version identifiers into account.
- **Faster cheat searches:** improved indexing and duplicate handling. PS2 gameplay cheats are presented separately from graphical patches.
- **More immersive touch controls:** visible button presses on compatible skins, with improved touch handling and control layouts.
- **Scraping crash fixed:** reduced memory usage when processing large game files, resolving the reported crash on iPhone 15 Pro Max.
- **Improved stability:** fixes for game startup, skins, shaders and game closing.
- **Easier first launch:** skip the initial game-folder selection and add your games later.

Cheat availability depends on the game, region and revision. Updated credits and third-party notices are also included.
