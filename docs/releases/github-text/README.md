# Public texts of the GitHub releases

Replacement bodies for the GitHub releases, worded without naming the
consoles or engines that the maintainer chose not to advertise publicly.
Paste each file into the matching release (Releases → Edit). The code and the
license notices are unchanged (see docs/LEGAL_AND_CREDITS.md, NOTICE.md and
assets/legal/).

Suggested repository description: **"Emulation frontend for iPhone and iPad:
one library, embedded engines, skins, achievements and per-game enhancements."**
