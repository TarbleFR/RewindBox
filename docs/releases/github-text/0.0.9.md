## RPCS3 improvements — Build 527

- Incremental JIT code publication avoids repeatedly processing previously published code ranges.
- Three PPU sum operations now use shorter ARM64/NEON sequences while preserving saturation and endianness.
- Recyclable GPU images now respect the existing 256 MiB / 256-image limits.
- Added bounded diagnostics for guest frame times, JIT preparation, component waits and memory usage.
- Includes the recent save-state restoration, worker shutdown and PPU cache fixes.

These changes are validated by native and packaging checks; gameplay FPS and total RAM gains on iPhone are still being measured. The first RPCS3 launch may rebuild affected caches.
