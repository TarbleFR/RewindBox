## RewindBox 0.0.10 — Build 559

Everything since 0.0.9-fix.1 (Build 530).

### Interface
- Refined Liquid Glass interface: one-line main header, a new "NeoStation" style (solid accent pill, matte surfaces, no blur), a working Interface preview with Apply/Revert, and floating side-menu bubbles in Settings and Scraper.
- New options in 12 languages: status bar items, accent colour, controller focus style, LB/RB glyphs and side-menu panel.
- ROM folder changes saved in quick succession no longer fail.

### PlayStation 3 (RPCS3)
- PS3 disc images (.iso) in your library folder now launch through RPCS3: RewindBox reads the disc, offers to install it into RPCS3 (with its .dkey/.key file) and boots it. Renamed or removed images stay in sync, and the original can optionally be deleted after installation.
- The God of War III profile is now actually applied; an old custom configuration previously disabled it silently.
- Engine improvements:
  - SPU code already in the cache loads without rebuilding the LLVM pass pipeline.
  - GPU copies that fully overwrite their destination no longer read the old contents back.
  - Fewer redundant texture hashes, plus a new experimental "Texture validation per FIFO batch" setting (automatic for God of War III only).
  - Faster lookup of identical vertex shaders, fewer copies during synchronous shader compilation, fewer redundant pipeline builds, and shader-cache writes moved off the RSX thread.
  - Less CPU spent waiting for the GPU, and faster JIT cache writes.
  - Public ARMSX3 fixes: SPU warm-up order, PKG path containment, debug SELF decryption, in-memory savestate files, cellSaveData SDK 2.6 limit.
  - ISO mounts are preserved when restoring a savestate.
- New experimental "MoltenVK Asynchronous Submits" setting (off by default).
- Additional bounded diagnostics (timeline, GPU waits, read-back origins, optimization counters) to measure performance.

The first launch of each PS3 game rebuilds its SPU cache once; the PPU cache is kept.

### Testing status
These changes passed automated native, sanitizer, ARM64 and packaging checks. FPS, stutter and memory gains on iPhone have not been measured yet. Please report results with your logs.
