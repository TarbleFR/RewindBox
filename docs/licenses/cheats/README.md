# Preserved upstream cheat notices — second review, 18 October 2026

These are supporting source-repository notices for the catalogue’s existing
imports. They supplement, rather than rewrite, its frozen metadata. Project
licenses do not automatically establish permission from all third-party code
authors; see the [review](../../SOURCE_RIGHTS_REVIEW_2026-10-18.md) and
[per-source register](../../CHEAT_CATALOG_SOURCES.md).

Full license texts are preserved verbatim. Mupen and Tyler files preserve only
their contiguous original notice headers, without cheat payloads. Admentus’s
credits are decoded from UTF-16LE with BOM to UTF-8; the text is unchanged.
[provenance.json](provenance.json) records immutable original URLs, original
and preserved hashes, transformations and scope.

NeoStation converts imported formats, selects executable complete programs and
builds identity indexes. These changes do not remove original author rights.
This directory is a repository archive; the current packager does not embed it.
It does not repair notice delivery in Build 479 or earlier IPAs. Before further
distribution, preserve the applicable notices with the converted data and
resolve the permissions and source obligations recorded in the review.

and [Luckysugar MIT notice](../../../packages/neo_cheat_catalog/ios/Resources/gow3-0100-LICENSE.txt)
remain in their original project locations.
