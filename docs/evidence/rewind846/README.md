# RewindBox 846 — ARMSX2 iOS 2.6.1

- Source amont `iOSv2.6.1` (`8bf12a1a42e5181a04e7e653ac94a95a47008e16`). L’IPA autonome jointe correspond à l’empreinte publiée par ARMSX2 (`bc656ab8376e1b91fbf91b335c40942c3fba45a9643bb08277ef0b365a986823`). Le framework intégré est recompilé depuis le tag avec le raccordement RewindBox, pour iOS arm64 et avec l’ABI 9. [Release amont](https://github.com/ARMSX2/ARMSX2/releases/tag/iOSv2.6.1)
- L’envoi de l’archive complète des sources a dépassé le budget du contrôle anti-IPA. La route compilation seule ne génère plus cette archive et garde le contrôle sur les artefacts envoyés. Elle rattache les entrées exactes et les onze fichiers amont modifiés au framework. Le run suivant a détecté le retrait du sélecteur Objective-C `isShaderChainSupported`. Le pont utilise la garantie de configuration et de liaison de librashader. [Premier run](https://github.com/TarbleFR/RewindBox/actions/runs/45793808685) · [Erreur Xcode](https://github.com/TarbleFR/RewindBox/actions/runs/45794284962) · [Core compilé, signé et authentifié](https://github.com/TarbleFR/RewindBox/actions/runs/45799354122)
- La recette standard a assemblé et signé la 846 depuis la 844. Les 49 empreintes retenues correspondent à la base. Les commits S2Arm concurrents restent différés. Le Core ARMSX2 et Runner ont changé comme prévu. Les différences du pont Dolphin sont limitées à la table d’édition de liens et aux stubs, avec les autres sections identiques à la 844. [Run IPA](https://github.com/TarbleFR/RewindBox/actions/runs/45803583105) · [Comparaison des sections](bridge-comparison.json)
- Les quatre pièces chiffrées, l’inventaire signé et l’IPA finale ont été vérifiés avant remise privée. Les suites Flutter et natives sont `not-run`. L’installation, les jeux et les performances sur iPhone restent non vérifiés. [Reçu](delivery.json) · [Vérification hors ligne](download846-verification.json)
