# Unified cheat catalogue — sources, authors and notices

This attribution record covers the **51 contributing source entries** in the
catalogue shipped with private **Builds 478 and 479**. It is documentation for
the development source tree; the current official release remains **0.0.7 / Build 455**.

The catalogue contains **2,395,549 programs/edition variants**, **50,284 typed
identity groups** and **51,652 transport records** in **874 packs**. Source
entries are import profiles, not necessarily independent projects or websites:
several profiles credit the same upstream collection. Contributions overlap
and must not be added together. These are not counts of unique effects or
distinct commercial games.

Index SHA-256: `a475a740a2e6251a5638077ffcce53c81afc125acd6fbcfaf97ff28d7602d1a1`.

  validation and native integration. It does not claim authorship of upstream codes.
