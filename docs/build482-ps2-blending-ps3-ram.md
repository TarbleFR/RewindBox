# Build 482 — précision du blending PS2 (ARMSX2, ABI 7) et information Get More RAM avant le firmware PS3, 18 octobre 2026

Demande du mainteneur : (1) un utilisateur ne trouve pas le réglage « Blending Accuracy » d'ARMSX2 dans les réglages du jeu ; l'exposer dans les paramètres graphiques PS2 et par jeu, uniquement avec les niveaux réellement pris en charge par le moteur embarqué, raccordé au moteur, priorité réglage global → profil automatique → choix propre au jeu ; (2) un message clairement visible avant l'installation ou la réinstallation du firmware PS3 : installer l'application Get More RAM et suivre sa procédure, puis revenir dans NeoStation ; (3) tests, IPA privée, documentation. Candidate : **Build 482**, construite par-dessus la Build 481 livrée (`839d1147`, run `39148545918`). Aucune release, aucun changement de `main`.

## 2. Ce que la Build 482 change

### 2.1 Core ARMSX2 — ABI 6 → 7 (`packages/armsx2_internal_bridge/core`, `ios/Classes/ARMSX2CoreABI.h`, `build-utils/armsx2/source.json`)

- `core/ARMSX2BlendingAccuracy.h` : constantes du moteur épinglé (`kNeoARMSX2BlendingDefault = 1`, `kNeoARMSX2BlendingMaximum = 5`, `kNeoARMSX2BlendingMedium = 2`) et la liste des niveaux offerts `{0, 1, 3, 4, 5}` avec `NeoARMSX2BlendingLevelOffered`. Medium n'est pas offert (§ 1) ; une valeur déjà écrite par un autre frontend est rapportée telle quelle, jamais réécrite.
- `core/ARMSX2BlendingAccuracy.inc` (inclus par `ARMSX2Core.mm`) : `get_blending_accuracy_json` (JSON : `available`, `global`, `game` (−1 = hérite), `effective` = `EmuConfig.GS.AccurateBlendingUnit` après GameDB, `gamedbMinimum` / `gamedbMaximum` / `gamedbRecommended` lus dans `GameDatabase::findGame(serial)->gsHWFixes`, `levels`) et `set_blending_accuracy(scope, level)` : scope `NEO_ARMSX2_BLENDING_SCOPE_GAME` (niveau offert, ou `NEO_ARMSX2_BLENDING_INHERIT` = −1 qui supprime la clé du jeu) ou `NEO_ARMSX2_BLENDING_SCOPE_DEFAULT` (niveau offert écrit dans `PCSX2.ini`, puis `flushINISettings`). Écritures sur le thread CPU possédé par ARMSX2, par les seuls accesseurs INI amont, relecture de contrôle, puis `applyGraphicsSettingsNow`. Un niveau hors liste (Medium compris), un scope inconnu ou l'absence de jeu sont refusés sans effet.
- Table `NeoARMSX2API` : deux entrées ajoutées en fin de structure ; `NEO_ARMSX2_ABI_VERSION 7u`, `abi_version: 7` dans `source.json`. Un Core ABI 6 est refusé par l'hôte (`kARMSX2ExpectedABI`).

### 2.2 Hôte (`Armsx2InternalBridgePlugin.mm`, `Armsx2SessionMenu.mm`, `ARMSX2InGameLocalization.mm`)

- Le plugin exige les deux nouveaux appels, ajoute `blending` à l'instantané de session et dispatche les commandes `blending` (jeu) et `blendingDefault` (défaut).
- Menu en jeu › **Graphismes** : ligne « Précision du blending » (rang 2, après Format d'écran ; Shaders, Overlays, Hacks graphiques et Patches directs décalés d'un rang) avec le niveau effectif et son origine (« Réglée pour ce jeu », « Ajustée par le profil ARMSX2/GameDB pour ce jeu », « Valeur par défaut de tous les jeux PS2 »). Sous-page `ARMSX2MenuBlending` à deux sections : **Ce jeu** (Automatique + les cinq niveaux) et **Valeur par défaut de tous les jeux PS2** (cinq niveaux), coches sur l'état courant, pied de section 0 « Appliquée actuellement : … » (+ recommandation GameDB si présente, + message de retour), pied de section 1 : « Une précision du blending plus élevée peut corriger certains effets (transparences, ombres, halos) mais augmente la charge du GPU et réduit les performances. Les changements s'appliquent immédiatement au jeu en cours… ». Les niveaux affichés viennent du JSON du Core : le menu n'ajoute jamais un niveau de son cru.
- 19 nouvelles clés dans `ARMSX2GraphicsTranslations` pour les douze langues (`en`, `fr`, `de`, `es`, `it`, `pt`, `ru`, `id`, `ja`, `ko`, `zh`, `zh_Hant`), dont « Unavailable », jusque-là sans traduction. Les valeurs existantes des utilisateurs ne changent pas : sans action, `PCSX2.ini` et les INI par jeu restent tels quels, défaut Basic.

### 2.3 PS3 — information Get More RAM avant le firmware (`lib/`)

- `lib/l10n/rpcs3_firmware_locale.dart` (douze langues, placeholders vérifiés) et `lib/widgets/rpcs3_firmware_preflight_dialog.dart` : dialogue affiché par `showRpcs3FirmwarePreflight(context, reinstall:)` dans les trois chemins d'installation du firmware (`Rpcs3InternalPlaylistActions` : porte de la bibliothèque et menu Importer › « Installer le firmware PS3 » ; `Rpcs3ManagerScreen` : bouton « Installer le firmware PS3 »), **avant** d'ouvrir le sélecteur de fichiers. Titre « Avant d'installer le firmware PS3 » ou « Avant de réinstaller le firmware PS3 » selon qu'un firmware est détecté. Contenu : la phrase du mainteneur telle quelle en tête ; pourquoi (RPCS3 a besoin de plus de mémoire qu'iOS n'en accorde par défaut ; Get More RAM ajoute la capacité « Increased Memory Limit » à l'App ID de signature, que NeoStation demande déjà sans pouvoir se l'accorder) ; les cinq étapes de l'application (installer avec SideStore/AltStore, Settings → compte Apple de signature, App IDs → Refresh → NeoStation → « Add Increased Memory Limit », réinstaller NeoStation, revenir) ; la distinction avec le fichier officiel `PS3UPDAT.PUP` demandé à l'étape suivante ; la précision que **NeoStation ne vérifie pas ici** l'état de la capacité (Continuer n'est qu'une prise de connaissance) ; l'adresse officielle `https://github.com/hugeBlack/GetMoreRam` (texte brut sélectionnable + bouton « Ouvrir la page », échec affiché) ; actions **Retour** (par défaut, B manette) et **Continuer vers le fichier du firmware**.
- Vérification des étapes : README du dépôt `hugeBlack/GetMoreRam` (wrapper StosSign/AltSign ; procédure Settings → sign in, App IDs → Refresh → app → « Add Increased Memory Limit », réinstaller depuis SideStore/AltStore) ; droit demandé par NeoStation : `com.apple.developer.kernel.increased-memory-limit` (`packages/neo_swap/ios/NeoSwapEntitlements.plist`, `docs/neoswap-build434-7go-envelope.md` § tableau des droits : « sans ce profil, SideStore le retire et la limite par défaut s'applique »).

## 4. Protocole d'essai sur l'iPhone

1. Lancer un jeu PS2 → menu en jeu › Graphismes : vérifier la ligne « Précision du blending » (Basique · Valeur par défaut de tous les jeux PS2) ; ouvrir, choisir Élevée dans **Ce jeu**, reprendre : l'effet est immédiat ; rouvrir : coche sur Élevée, pied « Appliquée actuellement : Élevée · Réglée pour ce jeu ».
2. Quitter, relancer le même jeu : la coche et la ligne doivent être conservées (INI `gamesettings/<serial>_<crc>.ini`).
3. Lancer un second jeu : Automatique coché ; changer **Valeur par défaut de tous les jeux PS2** → Complet ; revenir au premier : il garde Élevée.
4. Jeu connu de la GameDB avec `maximumBlendingLevel`/`recommendedBlendingLevel` : origine « Ajustée par le profil ARMSX2/GameDB pour ce jeu » puis, après un choix explicite, « Réglée pour ce jeu ».
5. PS3 : ouvrir la bibliothèque PS3 sans firmware → bouton Installer → le dialogue apparaît avant le sélecteur ; Retour ; Continuer → sélecteur `.pup`. Avec firmware installé : menu Importer › Installer le firmware PS3 et écran RPCS3 → titre « Avant de réinstaller… ».
