# Private Build 479 — compatible cheats without a catalogue-wide wait

The maintainer installed 478 and confirms Bladestorm BLES00113 reports revision 1.01. PS2/PS3 code lists take minutes to appear and include unwanted edition variants/duplicates. Work remains only on Claude. Reserve 479 for a new private IPA. No public release or emulator Core rebuild.

## Confirmed source causes and implementation

The first shared snapshot calls `hasChunk` once for every manifest row: 51,652 individual Foundation metadata checks, each previously performing two file-attribute lookups. Installation recovery now uses Apple's bounded directory attribute enumeration to collect regular-file names and data-fork sizes in batches. File sizes, symlink exclusion and missing-file recovery are preserved. Unsupported filesystems retain the original checked fallback. No code can reach an engine without its per-chunk SHA-256 check.

The previous query scans all rows for the console and also accepts title-only regional variants after a serial/CRC is known. A reusable typed-identifier index now limits discovery to the matching serial, executable CRC, PPU hash or other comparable typed identity. Known conflicting identifiers, versions, regions and languages are still rejected. All compatible source parts remain available; a known unmatched identifier does not fall through to USA/World editions with the same title. Explicit title search and candidates for a game without identifiers remain separate existing paths. Title folding is deferred until such a search is requested.

Verified program decoding is cached within bounded limits; bytes are hash-checked again before cache reuse. The direct list validates and prepares two parts at a time off main and publishes ready selections incrementally. It no longer waits for every matching part. Source duplicates are consolidated only for the same complete executable body and controls in the detected game scope. Complete conditional/dependency order, native PPU/version scope and exclusive controls are retained. Original selections and provenance remain attached; notes for FPS sources are aggregated. Unknown-edition candidates are not merged across distinct source editions. Saved native links are reused through all equivalent keys. Switch actions bind to a stable selection key so arriving rows cannot change the target of a user's gesture. Installation, discovery and import do not enable a code.

## Bladestorm 1.01 research boundary

The primary Artemis static file and NetCheat publication still attest the four BLES00113/BLUS30070 programs for 01.00 only. Global GitHub code search for `BLES00113 01.01` returned no entries; the reviewed `mohasi/game-cheats` BLES00113 source repeats the same four addresses without new version evidence. Artemis's versionless ChaosZage programs use array-of-bytes scanning; the retained Core's public patch ABI has no scan/read-memory adapter. Apollo's separate BLES00113 programs edit `PLAYDATA` saves and do not constitute runtime 1.01 patch evidence. No 1.01 program is invented or relabeled from 01.00. The real published 01.00 bytes must remain excluded for detected 01.01. The IRD disc version is not substituted for an executable compatibility proof.

The published 478 manifest, all packs, source provenance, language catalogue and FPS inventory remain unchanged. Native adapters, emulator settings, all precompiled engine/helper inputs, library and NeoSwap remain unchanged. This candidate targets lookup performance, edition selection and duplicate display; native/Simulator checks do not demonstrate physical iPhone timings or gameplay compatibility.
