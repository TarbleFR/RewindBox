# Source-rights implementation after the second review

Concealing Pokémon France's name does not create reuse permission. A written
grant can authorize the specified uses under its conditions; none is established
here. No upstream author has been contacted by this change.

An adequate written grant should come from the relevant rights holder and cover
the intended extraction, format conversion and redistribution through the app
and downloaded catalogue, including its attribution and funding conditions.
It does not automatically waive rights belonging to separate code authors.

## Pokémon France withheld

Eight executable programs across two French Rouge/Bleue transport records are
removed from the active index and pack payloads. Unrelated Libretro programs
for those games remain available. Two packs are replaced; the other **872 packs**
retain their published identities. Every unrelated chunk retains its exact bytes
and SHA-256. The [receipt](evidence/source-rights-withdrawal.json) records the
old/new index and pack identities. Three raw curated excerpts, including a
duplicate Rouge excerpt, are removed from the current source input too.

Future imports explicitly disable this profile. The updated loader also rejects
its source/import-tagged programs from older downloaded catalogues. Attribution
remains in the historical register and excluded-source metadata; the programs
are not kept under another source's name.

Current totals: **50 active profiles**, **2,395,541 programs**, **50,282 identity
groups**, **51,650 transport records**, **874 packs**. The 51-profile Build 479
publication remains identifiable in Git history.

Git history and previous IPA downloads are not erased. Previously imported
personal cheat files are not silently edited. Older applications need a catalogue
refresh for the new publication, and an app update for the new loader guard.
Re-enabling this contribution requires review of a written permission grant
or another established legal basis.

## Overlay attribution

The [creator inventory](OVERLAY_SOURCES_AND_CREDITS.md) preserves the supplied
credits for DJM, Marlon “Piixel” Alves, ZilogZ92 and Fercho. All 258 indexed CFG
headers were examined at the two pinned upstream revisions. Root and ancestor
notices are indexed for every entry. New converted installations retain the
exact original CFG, creator, immutable source URL, license URI, conversion
description and original notices. A required notice download failure prevents
installation.

Existing exclusions, control geometry and image lists are unchanged. Installed
copies require reimport/replacement with the updated app; earlier IPA contents
are not rewritten. Preserving notices does not invent missing upstream rights.

## Embedded engines

The [per-engine and 34-core inventory](EMBEDDED_RUNTIME_PROVENANCE.md) preserves
actual Build 479 identity records, separating source revisions, binary hashes
and license-reference snapshots. **Two cores have exact source revision evidence;
32 do not.** A guessed current HEAD or a copied license text does not close that
gap. No emulator core is rebuilt or replaced by this change.

KartPad's missing public translation inputs, RPCS3/host license compatibility
and the FBNeo/Patreon condition remain unresolved. This is not a full clearance
for redistribution.

## Checks and delivery boundary

Focused checks compare the real old/new publication, repacked payloads, all
unrelated chunk metadata and existing overlay layout fields. Apple Foundation
checks cover rejection of old source-tagged programs and cache reads; Flutter
checks cover preservation of notices and refusal when a required notice cannot
download. Actual CI results are recorded after execution. No new IPA, physical
iPhone gameplay validation, official release, tag or release asset is claimed.
