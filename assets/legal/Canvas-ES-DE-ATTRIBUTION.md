# Canvas (ES-DE) System Art Attribution

NeoStation iOS exposes Canvas (ES-DE) as a curated **external, on-demand**
System Art pack. The capsule images are not bundled into the NeoStation IPA.
NeoStation downloads, from the original repository, only the images of the
systems present in the user's library, when the user selects the pack.
