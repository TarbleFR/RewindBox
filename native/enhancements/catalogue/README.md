# RewindBox Cheats & Enhancements catalogue

Generated by `tools/enhancements/build_enhancement_catalog.py`; do not edit by
hand. Documentation: [`docs/ENHANCEMENTS.md`](../../../docs/ENHANCEMENTS.md).

- `index.json.gz` — catalogue keys per engine (Switch Title ID, PS3 serial,
  PS2 serial, Dolphin game ID or INI stem), per-category counts, sources with
  revisions and licence notes, and the size and SHA-256 of every shard. The
  same bytes are bundled as `assets/data/enhancements_index.json.gz`.
- `shards/<engine>-NN.json.gz` — the entries, downloaded by the application
  on demand for one game and verified against the index before use.
- `VALIDATION.json` — totals and the inputs the builder rejected.

Sources (pinned): HamletDuFromage/switch-cheats-db `109766ab21c7`, RPCS3 game
patches (patch.yml 1.2, content SHA-256 `f1f3cab0c8fe…`), PCSX2/pcsx2_patches
`ba8ef4f42c35`, Dolphin Sys/GameSettings of dolphin-ios `7cac54161659`. All
author credits present in the sources are kept in the entries. No game, BIOS,
firmware or key is part of this catalogue.
