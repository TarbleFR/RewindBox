# RewindBox Cheats & Enhancements catalogue

Generated by `tools/enhancements/build_enhancement_catalog.py`; do not edit by
hand. Documentation: [`docs/ENHANCEMENTS.md`](../../../docs/ENHANCEMENTS.md).

- `r/<revision>/index.json.gz` — catalogue keys per engine (Switch Title ID,
  PS3 serial, PS2 serial, Dolphin game ID or INI stem), per-category counts,
  sources with revisions and licence notes, and the size and SHA-256 of
  every shard. The newest index is bundled as
  `assets/data/enhancements_index.json.gz` and copied into the folder of
  every earlier revision of the same record format, where the apps holding
  that revision ask for it.
- `r/<revision>/shards/<engine>-NN.json.gz` — the entries, downloaded by the
  application on demand for one game and verified against the index before
  use. The shards of a published revision are never rewritten.
- `index.json.gz` and `shards/` at the root — the first publication
  (`2026-10-28.209508f70e51`), frozen for the apps that bundle it.
- `VALIDATION.json` — totals of the newest revision, the inputs the builder
  rejected, and what the publication changed.

Sources (pinned): 20, listed with revisions and licences in the index
(`sources`), in [`docs/ENHANCEMENTS.md`](../../../docs/ENHANCEMENTS.md) and in
`NOTICE.md`. A source is hosted only when its licence allows redistribution;
content the embedded engine already ships (ARMSX2 `patches.zip`) is
referenced by name only; a source without a licence (switch-cheats-db,
KeatonTheBot/switch-pchtxt-mods, StevensND/switch-port-mods,
StevensND/ue4-emuswitch-60fps, PCSX2/pcsx2_patches, PeterDelta/PCSX2,
Gabominated/PCSX2, Saramagrean/NetherSX2-cheats) is not hosted: the
shards hold names, credits and pointers, and the application downloads the
original file from the source at its pinned revision. The adapted RPCS3 entries are distributed under CC BY-SA 4.0
(RPCS3 Wiki contributors); the PS2 cheat files carry their MIT notices; the
Dolphin codes are GPL. Authors can ask for removal at
https://github.com/TarbleFR/RewindBox/issues. No game, BIOS, firmware or key is
part of this catalogue.
